# The screenshots in the README

Taken on the **dark / purple** theme with the window in **English**, and
written by `tools/app_shots.py`. If you retake them, retake **all six**:
mixing two grounds, or two languages, across the set makes the app look like
two apps.

```bash
python3 tools/app_shots.py assets/app
python3 tools/app_shots.py assets/app --recap 2026-08-29.answer.html
```

The newest recap and the newest idea are photographed unless you name another
one. Which page goes in is an editorial decision and sometimes a necessary
one: the newest recap of 29 August quoted a third party's Instagram handle in
its comment, and a README is a public place.

It drives the real window — the real archive, the real pages, the real
settings — with only the three POSTs that start work faked, so nothing is
spent and no model is called. `?native=1` is the switch the desktop shell
throws, so the padding and the rounded corners are the real ones; the traffic
lights are drawn in, because a browser has none and the set has always had
them. Six files, 1400px wide, JPEG — each is mostly a photograph, and PNG
stored the six at 2.9 MB against 600 KB.

| file | screen | what is in it |
|---|---|---|
| `home.jpg` | Home | posts waiting to be judged, with **Make the recap** and *Collect now* under it |
| `working.jpg` | Home, mid-run | the bar, the sentence and the clock — a run that is visibly alive |
| `recap.jpg` | a recap, open | the top of the page: the ratio, the comment, the painting |
| `archive.jpg` | Archive · All | the stack, with the ratios, the comments and the legend |
| `idea.jpg` | an idea | the weather, the die, the gist and the two facts |
| `theme.jpg` | Settings → Theme | three grounds and the row of accents |

⚠️ **Nothing personal on screen.** The archive shows your own titles and the
first line of your own recaps, and a browser behind the window shows the
account name in the URL — one candidate shot was dropped for exactly that.
The tool cannot know what is private: look at all six before committing.

⚠️ **The chrome follows the language; the judgement never does.** A page is
written once and never re-asked, so an archive built in one language still
reads in that language after the switch — which is right, and which shows in
the shots. For a set that is English all the way down, the recap and the idea
have to be *made* with the window in English.

`assets/CREDITS.md` records where the painting comes from. Screenshots of the
app itself need no credit — but if one ever contains somebody else's post,
it does.
